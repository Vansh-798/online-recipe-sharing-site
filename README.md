# Online Recipe Sharing Site

## Overview

**Online Recipe Sharing Site** is a Java-powered web application designed to connect cooking enthusiasts and facilitate the sharing, discovery, and discussion of recipes from around the world. Users can register, submit their own recipes, browse others' creations, comment, and interact in a vibrant food-focused community.

## Features

- User registration and authentication
- Submit, edit, and delete recipes
- Browse recipes with search and filter options
- Comment and rate recipes
- User profiles for managing submitted recipes
- Responsive design for desktop and mobile

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or above
- (Optional: Add required tools like Maven, Gradle, or an IDE, e.g., IntelliJ IDEA)
- (Optional: Database requirements, e.g., MySQL, PostgreSQL)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Vansh-798/online-recipe-sharing-site.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd online-recipe-sharing-site
   ```
3. **Build the project:**
   - With Maven:
     ```bash
     mvn clean install
     ```
   - Or with Gradle:
     ```bash
     gradle build
     ```
4. **Configure the database:**
   - Set up your database and update configuration in `/src/main/resources/application.properties` (or your configuration file).
5. **Run the application:**
   - With Maven:
     ```bash
     mvn spring-boot:run
     ```
   - Or with Gradle:
     ```bash
     gradle bootRun
     ```

### Usage

- Access the site at [http://localhost:8080](http://localhost:8080) (default port)
- Register a user, browse or share recipes, leave comments, and rate dishes.
